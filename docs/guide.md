# راهنمای Karvan

Karvan کار شما با Claude Code را بین کامپیوترهایتان جابه‌جا می‌کند: گفتگوها (برای `claude --resume`)، فهرست
گفتگوهای بخش Code اپلیکیشن دسکتاپ، `CLAUDE.md`، مهارت‌ها، حافظه‌ی پروژه‌ها و (اگر بخواهید) کار نیمه‌تمام git.

> ابزار غیررسمی است؛ Anthropic آن را نساخته و تأیید نکرده.

> **مهم (نسخه‌ی M0):** داده‌ها هنوز رمزنگاری نمی‌شوند (رمزنگاری در M1 می‌آید). فقط از repo ی **خصوصی** یا
> پوشه‌ای استفاده کنید که فقط خودتان به آن دسترسی دارید. Karvan repo ی عمومی GitHub را رد می‌کند.

## نصب

فعلاً از سورس (به Go 1.26 یا جدیدتر نیاز دارد):

```sh
git clone https://github.com/leberman/karvan.git
cd karvan
go build -o ~/.local/bin/karvan ./cmd/karvan
karvan version
```

بسته‌ی `.deb` با انتشار عمومی (M2) می‌آید.

## راه‌اندازی (یک بار روی هر سیستم)

۱. یک محل ذخیره انتخاب کنید که همه‌ی سیستم‌ها به آن دسترسی دارند:

- **repo ی خصوصی git** (برای برنامه‌نویس‌ها): روی GitHub یک repo ی **خصوصی** و خالی بسازید، مثلاً
  `karvan-data`. اگر شبکه‌تان SSH روی پورت ۲۲ را می‌بندد، از نشانی پورت ۴۴۳ استفاده کنید:
  `ssh://git@ssh.github.com:443/<you>/karvan-data.git`. یک بار `ssh -T -p 443 git@ssh.github.com` بزنید و
  اثر انگشت را با صفحه‌ی GitHub مقایسه کنید.
- **پوشه‌ی ابری**: هر پوشه‌ای که Dropbox، Google Drive، OneDrive یا Syncthing همگامش می‌کند.

۲. اجرا کنید:

```sh
karvan init
```

`init` این‌ها را می‌پرسد یا خودش انجام می‌دهد:

- اسم این سیستم (مثلاً `work` یا `home`)؛ روی هر سیستم باید فرق کند؛
- محل ذخیره؛
- **پوشه‌هایی که در آن‌ها با Claude Code کار کرده‌اید** را خودش از گفتگوهای قبلی پیدا می‌کند و پیشنهاد می‌دهد.
  هر پروژه با remote ی git اش شناخته می‌شود، پس لازم نیست روی سیستم‌ها در یک مسیر باشد (`~/work/app` این‌جا،
  `~/temp/app` آن‌جا)؛
- اینکه کار نیمه‌تمام git هم جابه‌جا شود (پیش‌فرض: نه)؛
- دو hook در Claude Code (`SessionStart` و `SessionEnd`) با احتیاط به `~/.claude/settings.json` اضافه می‌کند (اگر
  فایل JSON ی نامعتبر باشد، دست نمی‌زند و می‌گوید)؛
- یک timer ی systemd که هر ۱۰ دقیقه و موقع خروج و خاموش شدن همگام می‌کند؛
- یک بار همگام‌سازی.

بدون ترمینال (مثلاً در اسکریپت):

```sh
karvan init --machine work --git ssh://git@ssh.github.com:443/<you>/karvan-data.git --project ~/work/app --yes
```

۳. روی سیستم دوم همین کار را با **همان** محل ذخیره و اسم دیگری بکنید.

## استفاده‌ی روزمره

هیچ کاری لازم نیست. Karvan خودش موقع شروع و پایان هر گفتگوی Claude Code و هر ۱۰ دقیقه همگام می‌کند. روی سیستم
دیگر، `claude --resume` گفتگوهای سیستم اول را هم نشان می‌دهد.

| فرمان | کار |
| ---- | ---- |
| `karvan status` | آخرین همگام‌سازی، سیستم‌های دیگر، تداخل‌ها، چیزهای منتظر |
| `karvan sync` | همگام‌سازی همین الان |
| `karvan restore` | آوردن کار نیمه‌تمام git از سیستم دیگر (داخل پوشه‌ی پروژه اجرا کنید) |
| `karvan doctor` | بررسی تنظیمات، hookها، timer، محل ذخیره و شبکه |
| `karvan init` | تغییر تنظیمات یا اضافه کردن پروژه (هر وقت) |
| `karvan uninstall` | حذف hookها و timer (داده‌ها و تنظیمات می‌مانند) |

## چه چیزی منتقل می‌شود

| مورد | توضیح |
| ---- | ---- |
| `~/.claude/CLAUDE.md` | دستورالعمل‌های کلی |
| `~/.claude/CLAUDE.machine.md` | **هرگز**: دستورالعمل مخصوص همین سیستم؛ `init` آن را می‌سازد و از `CLAUDE.md` صدا می‌زند |
| `~/.claude/skills/` | به‌جز `skills/synced/` (مال اپلیکیشن است) و مهارت‌هایی که در `exclude.skills` نوشته‌اید |
| حافظه‌ی هر پروژه | `~/.claude/projects/<پوشه‌ی پروژه>/memory/` |
| گفتگوها | گفتگوهای ۷ روز اخیر (قابل تنظیم) با subagentها و خروجی‌های ذخیره‌شده‌ی ابزارها |
| فهرست گفتگوهای اپلیکیشن دسکتاپ | فقط گفتگوهایی که خودشان منتقل می‌شوند |
| کار نیمه‌تمام git | فقط اگر برای آن پروژه روشن کنید (`wip = true`) |
| پوشه‌های شخصی | هر پوشه‌ای که در `items.folders` اضافه کنید |
| `settings.json`، اطلاعات ورود، `.env` | **هرگز** |

## وقتی هر دو سیستم یک چیز را عوض کرده‌اند

- **گفتگو:** خطوط هر دو طرف با هم ترکیب می‌شوند؛ هیچ خطی حذف نمی‌شود. اگر یک گفتگو روی هر دو سیستم ادامه پیدا
  کرده، هر دو شاخه در فایل می‌مانند.
- **`CLAUDE.md`، حافظه، مهارت‌ها:** اگر خط‌های متفاوتی عوض شده‌اند، خودکار ادغام می‌شوند. اگر یک خط را دو جور
  عوض کرده‌اید، نسخه‌ی جدیدتر می‌ماند و دیگری کنارش با اسم `<اسم>.conflict-<سیستم>` ذخیره می‌شود. خودتان ادغام
  کنید و فایل `.conflict-` را پاک کنید؛ `karvan status` آن را نشان می‌دهد.
- **حذف در برابر تغییر:** تغییر برنده است؛ فایلی که روی یک سیستم پاک شده ولی روی دیگری عوض شده، برمی‌گردد.

## اپلیکیشن دسکتاپ

اپلیکیشن فهرست گفتگوهایش را فقط موقع باز شدن می‌خواند و وقتی باز است ممکن است نسخه‌ی خودش را رویش بنویسد. پس
Karvan گفتگوی **جدید** را هر وقت اضافه می‌کند، ولی گفتگوی موجود را فقط وقتی اپلیکیشن بسته است عوض می‌کند. اگر
پیام «Quit it with Ctrl+Q and open it again» دیدید، اپلیکیشن را با Ctrl+Q کامل ببندید و دوباره باز کنید.

## کار نیمه‌تمام git

اگر برای پروژه‌ای روشن باشد، Karvan در هر همگام‌سازی از کار نیمه‌تمام عکس می‌گیرد: شاخه، commitهایی که هنوز
روی هیچ remote ای نیستند، تغییرات staged و unstaged، و فایل‌های جدیدی که git نادیده نمی‌گیرد (تا ۲۰ مگابایت).
روی سیستم دیگر، شروع Claude Code می‌گوید «unfinished work from work ... is waiting». داخل پوشه‌ی پروژه:

```sh
karvan restore
```

می‌گوید چه پیدا کرده و می‌پرسد. Karvan هرگز در پروژه‌ی شما commit، push، stash یا reset نمی‌کند، و اگر تغییرات
ثبت‌نشده‌ی محلی داشته باشید، کاری نمی‌کند. merge یا rebase ی در جریان را نمی‌شود جابه‌جا کرد؛ این را می‌گوید.

## فایل تنظیمات

`~/.config/karvan/config.toml`، مخصوص همین سیستم و هرگز منتقل نمی‌شود. نمونه:

```toml
version = 1
machine = "work"

[store]
kind = "git"
url = "ssh://git@ssh.github.com:443/you/karvan-data.git"
branch = "main"

[sync]
history_days = 7     # گفتگوهای چند روز اخیر
interval = "10m"     # هر چند وقت (timer)
skip_recent = "15m"  # timer گفتگویی را که همین الان باز است نمی‌فرستد
timeout = "5m"

[items]
claude_md = true
skills = true
memory = true
transcripts = true
desktop = true

[[projects]]
id = "github.com/you/app"
name = "app"
path = "/home/you/work/app"
wip = true

[exclude]
skills = ["work-only-skill"]
```

## اشکال‌یابی

| مشکل | راه |
| ---- | ---- |
| «could not reach ... in time» | شبکه SSH روی ۲۲ را می‌بندد: نشانی repo را به `ssh://git@ssh.github.com:443/...` عوض کنید (`karvan init --git ...`). |
| «... is not in ~/.ssh/known_hosts» | یک بار `ssh -T -p 443 git@ssh.github.com` (یا بدون `-p 443`) و تأیید اثر انگشت. |
| «settings.json is not valid JSON» | فایل را درست کنید (مثلاً کامای اضافه)؛ Karvan به فایل نامعتبر دست نمی‌زند. |
| «another machine is writing under this machine's name» | دو سیستم یک اسم دارند: روی یکی `karvan init --machine <اسم دیگر>`. |
| «the store went back in time» | کسی تاریخچه‌ی repo را با force عوض کرده یا از پشتیبان برگردانده؛ Karvan برای جلوگیری از گم شدن داده متوقف می‌شود. |
| گفتگو «may be open» | گفتگو در ۱۵ دقیقه‌ی اخیر نوشته شده؛ بعد از بستنش، دور بعد ادغام می‌شود. |

همیشه `karvan doctor` و `karvan status` اول بزنید. لاگ اجرای پس‌زمینه در `~/.local/state/karvan/log/` است.
